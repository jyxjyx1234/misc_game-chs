AlphaActivation通用注册工具 100723版 适用至110729变种版本

这是适用于2010年7月之后发布的AlphaActivation签名规格的注册工具。
不适用于更早的版本，如需使用请使用之前的版本。
目前支持包括11/07/29在内的三种变种，共计四种模式。
(包含了alsignup_act_100723.exe/101224.exe/100723b.exe的全部功能)

●适用范围(截至2011/07/29)
从10/07/02的Executor Script到11/07/29的黑虹本2等AlphaActivation游戏
※但不包括FlyableCandyHeart(请使用为110527变种提供的110225版)
※不适用于此前的游戏

●使用方法
启动后会监视AlphaActivation认证程序的启动，
当游戏启动或已经启动时，将自动创建认证文件。
创建完成后，如果出现认证界面，请先取消并重启游戏。
第二次及以后的启动无需再次认证。

认证文件将保存在：
2K/XP系统: C:\Documents and Settings\All Users\Application Data\ASign
Vista/7系统: C:\ProgramData\ASign
以[AlphaID].sig的形式存在。
