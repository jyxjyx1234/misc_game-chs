# 使用方法

将补丁中的内容覆盖到游戏目录，从MATNTR_CHS.exe启动。

如果启动不成功请先尝试安装 https://aka.ms/vs/17/release/vc_redist.x86.exe 后重启。

以进行WIN10兼容，但是未测试该兼容补丁是否能在WIN7运行。如果使用的WIN7以下的系统，可以将win10_patch.dll删掉，并将hook.ini中的WIN10PATCH=1改为0。
