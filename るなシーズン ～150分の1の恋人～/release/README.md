# 使用方法

已免CD、免安装。需要在简体中文(CP936)环境下运行。

将镜像中的WAVE和PROGRAM文件复制出来，然后将WAVE文件夹移动到PROGRAM文件夹中（PROGRAM文件夹可以任意改名）。然后将本补丁复制进游戏文件夹，从LUNA_CHS.exe启动即可。第一次启动有概率会提示需要CD，退出后重新启动游戏就行了。

如果启动不成功请先尝试安装 https://aka.ms/vs/17/release/vc_redist.x86.exe 后重启。
