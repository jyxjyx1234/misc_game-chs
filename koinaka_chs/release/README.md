# 使用方法

务必安装1.01d修正补丁。

将补丁中的内容覆盖到游戏目录。从koinaka_CHS.exe启动游戏，无需转区。

中文版存档在savechs文件夹中，与生肉存档不通用。

如果启动不成功请先尝试安装 https://aka.ms/vs/17/release/vc_redist.x86.exe 后重启。
