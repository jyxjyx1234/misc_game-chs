# 使用方法

使用本补丁前，请先删除原本的ISF文件。

为了减小补丁体积，以及保证与其他补丁的兼容，补丁中没有包含修改后的主程序，需要通过运行脚本来生成。将本补丁的内容放入游戏目录，运行install.cmd（目录下需要有ROSYU2.exe文件，不能改名）。从生成的ROSYU2_chs.exe启动。转区可以避免部分ui乱码，不转区影响不大。

与站内的免dvd补丁兼容（但是实测站内的免dvd补丁有小问题，不挂载dvd时部分文件缺失，免安装会导致存档异常）。先安装免dvd补丁（ROSYU2.exe文件，不能改名），然后再运行install.cmd。

Win10有概率不能启动，原因不明（我有时候能打开，有时候开不了，很奇怪）。建议使用win7虚拟机。
