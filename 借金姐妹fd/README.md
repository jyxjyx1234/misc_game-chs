这是借金姉妹2 AfterStory的文本提取和替换工具。

# 使用说明：

将本工具的内容放入游戏目录。

程序会自动调用LocaleEmulator.dll，无需手动转区。

hook.ini中最后一行设置为MODE=1时，为文本提取模式。此时进行游戏时，游戏的文本会被提取到游戏目录下的output.txt中（utf16le编码）。游戏中可能会出现换行符\r，提取时会被替换为符号“@”。

hook.ini中最后一行设置为MODE=2时，为文本替换模式。此时程序会读取游戏文件夹下的trans.dat文件。此文件需要为utf16le编码，格式为：原文:::译文（参见示例）。原文需要与提取到的output.txt中完全严格一致，译文中不能出现“\n”，“\r”需要替换为“@”。游戏会显示替换后的文本。

如果有需要，hook.ini中的FONTNAME处可以修改游戏调用的字体（通常使用Microsoft YaHei UI就可以）。
