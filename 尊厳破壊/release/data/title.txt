//	ボタン
//	id:
//		tフラグのインデックスに対応

//	page:
//		normal	標準で表示する
//		extra	extraを選んだときに表示する
//	tag:
//		start		スクリプトを開始する(初めから、おまけシナリオ)
//		continue	ロード画面を開く
//		cgmode		CGモード画面を開く
//		scenemode	回想モード画面を開く
//		bgmmode		BGMモード画面を開く
//		config		設定画面を開く
//		extra		extraメニューに切り替え
//		return		通常メニューに切り替え
//		exit		ゲーム終了
//		url			urlをブラウザで開く
//	image:
//		ボタンファイル名
//	x,y:
//		表示座標
//	cursor:
//		マウスオーバー時のカーソル形状
//		voidを指定するとsetting.txtで指定したデフォルトのまま変更しない
//	visible:
//		true:初期設定で表示する
//	object:
//		type=start	スクリプト名
//		type=url	URL
