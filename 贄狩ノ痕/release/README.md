# 使用方法

将补丁中的内容覆盖到游戏目录。不要有中文路径！！！从niekari_chs.exe启动。无需转区。请勿安装字体。

游戏内可以更改主角姓名，但是本补丁没有适配，请使用默认姓名。

如果启动不成功请先尝试安装 https://aka.ms/vs/17/release/vc_redist.x86.exe 后重启。

# 游戏安装方法

本游戏有两张盘。分别解压，将其中的所有dat文件复制到任意目录下（路径不要有中文）。再放入本补丁，即可启动。
