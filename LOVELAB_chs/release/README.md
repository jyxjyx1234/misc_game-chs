# 使用方法

从 `LoveLab_CHS.exe`启动。

如果启动不成功请先尝试安装 https://aka.ms/vs/17/release/vc_redist.x86.exe 后重启。

默认使用Microsoft YaHei UI字体，如果没有请自行下载（找不到可以去我Natural Another One 2nd -Belladonna-这个补丁里找msyh.ttc文件并安装）。

如果安装过其他人提供的修改过的Microsoft YaHei UI字体，请将其卸载并安装未经修改的Microsoft YaHei UI。

如果需要更改字体，请在hook.ini中的相应位置更改（字体名只能为纯英文）。如何查看、更改字体名请自行百度。非默认字体带来的问题不提供支持。
